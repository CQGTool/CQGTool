# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not create a public GitHub Issue.

Please report the vulnerability privately to the repository maintainers.

When reporting a vulnerability, please include:

- Description of the vulnerability
- Steps to reproduce
- Affected version
- Potential impact
- Suggested fix, if available

We will review the report and respond as soon as possible.

## Supported Versions

We currently support the latest released version of the project with security updates.
